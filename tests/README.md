# 品質檢查

使用 Node.js 內建測試工具，無需新增套件：

```text
node --test tests/quality-regression.cjs
```

請透過 HTTP 伺服器開啟遊戲；responsive-preview.html 可檢查四種內容尺寸。此頁使用本機 ?dev=1 預覽，不應代替真實裝置、多點觸控、麥克風或效能驗收。詳細範圍與限制見 ../docs/QUALITY_IMPROVEMENTS_2026-10-10.md。

## 本機穩定性驗收
1. 以 ?dev=1 開啟 localhost 預覽，進入遊戲並開啟冒險選單。
2. 選擇固定畫質，避免巡檢中自動降級影響比較。
3. 「暖機＋巡檢十界兩輪」會依序切換三十次：第一輪暖機，後兩輪量測。素材逾時保留失敗計數，不會無限等待。
4. 巡檢結束返回原場景，下載檢查紀錄。比較 round 1 與 round 2 同場景／同畫質的 geometries、textures 與 drawCalls。
5. 如需中止，可重新開啟冒險選單按停止巡檢；頁面進入背景亦中止，不將背景幀加入效能統計。
6. 長時間遊玩時可隨時匯出紀錄；p95Ms 是最近最多 1800 個可見遊戲幀的第 95 百分位，longFrames 累計超過 50ms 的幀。資源數不等同完整 GPU 或系統記憶體。

正式網址無診斷介面；紀錄只透過本機下載，不會傳送到雲端。
真實多點觸控、真實麥克風與 30 分鐘硬體驗收，仍須在目標設備執行。

## 語音容錯覆蓋
測試模擬權限拒絕、服務不可用、無麥克風、網路失敗、沒有聲音、啟動失敗、逾時與未取得最終結果。
也涵蓋取消後的舊回呼、單字轉整句、示範語音中斷錄音、老師驗證與辨識回呼衝突，以及單字邊界比對。
這些模擬測試不等於真實麥克風辨識品質驗證。
