# 英語魔法探險家：秘境逃脫任務

國小英語學習與密室逃脫瀏覽器遊戲，版本 **2.8.0（本機開發版）**。使用 Three.js、原生 JavaScript 與 Google Apps Script。正式網站：https://hs5743.github.io/whimsy-forest-escape/

## 遊戲內容

- 十個主線空間、十個主題支線，以及英語學習大廳，共二十個遊戲場景與一個自由學習空間。新港國小圖書館、創客工坊與校慶彩繪工坊接在校園迎賓後；數字嘉年華接在市集任務後。
- 大廳可自由練習 622 個詞項、十五個主題與 140 個句型。618 個詞項來自 GEPT Kids 參考字表；另有四個明確標示為字表外的創客延伸詞。
- 新章節保留指定口說通關條件。WASD／方向鍵移動、拖曳環視、E 互動；觸控裝置另有操作控制。
- WebGL 啟動失敗時自動改用圖卡互動。圖卡與 3D 共用物件可見性及解謎門檻；可在保留進度下重新嘗試 3D。
- 遊客存於本機；已綁定學生的通關事件先保存到裝置，再重試送往雲端。冒險位置／道具續玩與學習紀錄是不同服務，請分別看其同步狀態。

## 本次修正

本機增添 zone19「魔法數字嘉年華」，承接陽光微風市集任務。玩家逐站數點燈、星籌及嘉年華道具，學習 13–20 共八個未重複 GEPT 數字詞；每一步仍須先選線索再口說辨識通過。場景加入四張生成材質與道具圖，創客工坊上牆的解說卡已換成高窗、零件收納及實際工作區細節。學習大廳增加八個詞、八張句型卡及一個主題，現有總量為 622 個單字、132 張句型卡及十四個主題。

本機另增 zone20「新港校慶：舞獅彩繪工坊」，接在新港國小迎賓任務之後。校園場景改為草地前景與弧形跑道，並補上校舍、旗桿、松樹及花台細節；工坊加入舞獅壁畫、黑板、工具桌與材料展示，入口視線已校正為先看到壁畫，雙語展示卡移到側邊。八個步驟都要先找到對應實物，再通過口說辨識；新增八張情境句卡與一個主題。八個 GEPT 核心詞首次配置到章節關卡，但早已存在於完整大廳字庫，因此字庫維持 622 個詞項，句型為 140 張、主題 15 個。

GAS 新增持久事件回條，讓冒險與大廳共用可恢復總額；中途寫入失敗後能重試修復 Students 與 Passport_Logs。教師維護驗證改在後台執行。公開前端 token 只是應用標記，不能視為學生身分驗證或防作弊機制。

## 開發與驗證

使用 Node.js 24 或相容版本，無需安裝測試套件：

```sh
npm test
npm run build:gas
```

透過 HTTP 靜態伺服器開啟，不要直接開啟 file://。localhost 加上 ?dev=1 會啟用不傳成績的場景檢查，可巡檢二十個遊戲場景與大廳。測試範圍與硬體驗收限制見 [tests/README.md](tests/README.md)。
