# v2.6.0 — 玻璃溫室與畫面細節交接

日期：2026-10-17。基底：d0493078002a27c46088073f40661117c3f868f7（v2.5.1）。本次新增一個可完整通關的章節；現有十主線、四支線與學習大廳，共十五空間。

## 入口與遊玩

第三關「守護獸之森花園」完成 TREE／RABBIT／BIRD 三位夥伴照護後，前往西南側玻璃拱廊（約 x=-10.2、z=7），進入「玻璃溫室：花園復甦任務」。進入另需 Lv.2，保留既有 accessLevel。一般場景出口返回原花園；星圖保留目前正式版可傳送到其他已解鎖空間的規則，新支線不額外解鎖高階關卡。星圖顯示支線連結與解鎖說明；沒有另外添加首頁捷徑。

任務依序：接委託 → 葉色 → 蜜蜂 → 蝴蝶 → 調整水分／光線 → 溫柔聞花 → 分類三件遺落物 → 花園明信片。每步的操作證據完成後，仍要由當次口說辨識通過才推進；不使用教師略過。PICK UP 必須說完整片語。錯誤操作可重試，保留前面口說成果。

## 畫面與聲音

新增可環視玻璃屋骨架、透光屋頂、窗格陰影、石材花台、排水溝、曲面葉片與葉脈／凹凸紋理、花朵、植栽盆緣、昆蟲模型與有實體支架的展示標示。植物有不同高度與朝向，細節採固定種子與批次繪製，避免每次進場累積隨機資源。

原花園新增玻璃前廊、拱架藤葉、花盆及石板入口。溫室的幼苗會在 GROW 口說通過後長大；分類與口說完成後清掉遺落物；全關通過後花台綻放。減少動畫設定可停止昆蟲浮動與翅膀擺動。新增三拍玻璃音／撥弦原創配樂，沿用跨場景切換與口說音量避讓。

本版使用原生 3D 與既有貼圖，沒有新增外部圖片生成依賴；未覆寫校園參考照片。

## 工程整合

- greenhouse-chapter.js：純規則、八步證據、資料清洗、提示、UI 與辨識會話。過期、取消、重複回呼及離開場景後不能推進。
- greenhouse-scene.js：模型、碰撞、站點、入口與同步視覺。所有九個互動目標與提示目標對應，主要走道與出口可通行。
- spatial-zone-manager.js、realm-quests.js、realm-presentation.js：zone14 元資料、支線門檻、星圖、任務與切換。
- adventure-assist.js、game-polish.js、vocab-data.js、scene-music.js：提示、材質光線、例句與專屬音樂。
- adventure-cloud.js、gas/AdventureCheckpoints.gs：後台以 schemaZones 明確宣告新關卡。存檔含溫室狀態而後台不支援時停止上傳，即使已回到舊關卡亦不會漏存後回報成功；本機紀錄保留。
- scripts/build-gas-schema.cjs：用同一份純規則產生後台驗證器。
- scripts/build-gas-bundle.cjs：修正完整單檔的 window／globalThis 作用域，使純模組私有且完整檢查點路由可使用；新增測試實際儲存／讀回新關卡，不只測 capabilities。

## 驗證

**272 項自動測試通過**，包括原有 261 項及新增 11 項，沒有跳過。結果見 [v2.6.0-tests.txt](validation/v2.6.0-tests.txt)。包含錯誤設定、唯一分類、完整片語、各階段存檔、偽造進度清洗、支線限制、模型有限值與批次、入口門檻、辨識回呼及單檔後台真實路由。

本機瀏覽器已檢查 3D 畫面，並在強制無 WebGL 的圖卡模式完成八步口說流程，核對錯誤水分不啟用通關、只說 pick 不通過、正確 pick up 可推進及通關後重新載入仍保留。語音結果使用獨立本機測試工具模擬，不寫入正式學生資料，未宣稱完成真實麥克風品質驗收。

固定 medium 的十五空間三輪巡檢完成 **45 次切換、0 素材失敗**，見 [原始紀錄](validation/v2.6.0-scenes.json)。溫室三輪均為 geometries 41、textures 57、drawCalls 217。巡檢整體最終最近 1800 幀 p95 為 17.7ms，含切換與暖機影響，非個別場景穩態效能，也不替代 30 分鐘實機測試。
