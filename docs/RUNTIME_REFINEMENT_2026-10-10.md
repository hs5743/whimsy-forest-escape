# 流暢度與運算精進紀錄
日期：2026-10-10。接續 3b61dd8 已發布版本。

## 完成項目
- 標題頁、指南與彈窗期間，3D 背景最多每 50ms 更新一次（上限 20 次／秒）。探索畫面依瀏覽器更新節奏立即恢復。介面本身的按鈕與 CSS 動畫不受此節奏限制。
- 閱讀、背景頁籤、顯示中斷及第一個恢復幀不納入自動畫質判定或幀時間統計；恢復時第一幀的移動時間為零，避免將等待時間帶入移動。
- 互動選取重用每個世界專屬的向量、包圍盒及射線結果陣列；每次結束清除道具參考，射線僅檢查互動距離，成功或錯誤都恢復原距離設定。保留朝向、遮擋與小物件輔助規則。
- 降低動態效果涵蓋書齋塵埃漂浮。畫面中斷時清除操作與錄音，恢復時再清除累積輸入，重新開始幀節奏。
- 本機診斷在閱讀期間標記背景省電，不把先前的探索 FPS 當成當前閱讀幀率。
- 更新腳本版本參數，讓正式頁面載入本輪新版。

## 驗證
- 70 項回歸檢查全部通過；新增穩定閱讀節奏、隱藏／中斷恢復、選取暫存重用與清除、異常復原、恢復不跳位，以及顯示中斷操作重設。
- 本機瀏覽器實際完成標題 → 操作說明 → 進入書齋、W 移動、E 互動、開關選單及降低動態設定。提示與實際魔導書互動一致；瀏覽器錯誤紀錄為空。
- 顯示中斷採事件模擬，沒有冒稱硬體失效恢復、真實裝置多指或麥克風驗收。背景更新頻率是程式限制，不宣稱所有設備 FPS 提升幅度或省電量。
- 本輪未重作全部美術素材；焦點是可量測、可回歸的流暢度修正。

## 雲端驗證重點
在正式網址閱讀指南一段時間後進入遊戲，確認操作立即恢復、位置不跳動；探索中反覆開關選單，再檢查畫質與道具互動。
