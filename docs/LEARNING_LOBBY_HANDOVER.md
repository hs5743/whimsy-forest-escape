# 英語探險家學習大廳（2026-10-23 更新）

## 遊戲功能

從見習書齋、空間星圖或冒險選單進入。Lv.1 即可使用；返回時恢復進入前的關卡、位置與朝向，從大廳不可跳到其他未完成的主線。

- 狐狸館長：學習大廳目前共 622 個詞項、15 個主題；其中 618 個來自使用者提供的 GEPT Kids 參考字表，另有 4 個清楚標示的創客補充詞。可用英文／中文搜尋。
- 貓頭鷹老師：目前共 140 組練習句卡。新港國小創客工坊增加 8 個 GEPT 核心詞、4 個選修補充詞與 12 張情境句卡；zone19 魔法數字嘉年華增加 8 個未重複 GEPT 數字詞及 8 張數數句卡；zone20 舞獅彩繪工坊增加 8 個未重複關卡核心詞、8 張情境句卡與一個主題。zone20 使用的八個 GEPT 詞本來已在大廳詞庫中，因此詞項總數不變。舊有 a/an、可數名詞、食品複數與動詞配詞規則保持一致。
- 兔子教練：已學字按最近練習日期排序，方便跨日複習。
- 收藏牆：自由增減收藏，收藏與已完成口說分開記錄。
- 正常／慢速示範、分段拼讀、字義小檢查、下一題、不限次數重練。

大廳口說使用完整內容與順序比對。這是語音辨識內容檢查，沒有提供音素級發音評分。辨識失敗、關閉視窗、換題或換學生都不能增加積分。

## 大廳獎勵

首次口說單字 +50 XP；舊關卡已學字不再領取首次獎勵。大廳每日前兩次有效單字複習各 +10 XP；之後仍累積練習次數。首次口說同一組完整句型 +30 XP；句型重練不再加 XP。句型不會直接把其組成單字標示為已學。

單字熟悉度：已口說、累積三次、跨兩天、字義答對、跨三天且在句型使用；在同一天反覆朗讀不能直接變成五星。舊關卡的既有積分制度保持原有行為。

## 保存與此次部署狀態

使用 `whimsy_learning_v1:<studentId>` 在此裝置保存，與其他學生分開；同一學生重新登入保留本機積分。當前訪客的學習紀錄可帶到下一次學生登入。

**使用者選擇先部署遊戲、後台提供更新檔。因此本次沒有修改正式 Apps Script，也沒有啟用大廳的跨裝置同步。** 畫面標示本機保存／後台尚未更新；事件保留在待傳列表。既有關卡的原學習紀錄服務繼續使用原網址。

## 後台更新（保留原資料與服務網址）

1. 開啟使用者提供的 Apps Script 專案，先另存現有程式及部署版本資訊。不要執行 `initSpreadsheet`，不要清空 Students、Passport_Logs 或 Config。
2. 新增兩個指令碼檔：`LearningSchema.gs` 與 `LearningHub.gs`，貼入此版本的同名檔案。
3. 在現有 `doPost` 中，保留原鎖定、校本 token 驗證與所有原 action。在 **token 驗證成功之後**、原其他 action 分支之前加入以下路由（`ss` 是原有試算表物件）：

```javascript
if (action === 'learningGet' || action === 'learningEvent') {
  return makeJsonResponse(learningHubAction(payload, ss));
}
```

4. 管理部署 → 編輯原本的網頁應用程式部署 → 建立新版本。沿用原執行身分、存取權與服務網址，不另開公開權限。不必改前端網址。
5. 正式遊戲使用既有學生登入後，進入大廳按「重試同步」。確認出現「大廳紀錄已同步至雲端」，並以第二台裝置驗證收藏與紀錄。勿以真實學生帳號寫入測試分數。

新增 `LearningProfiles` 表格由學習服務需要時建立，不改動既有表格格式。新增服務在原 `doPost` 鎖定中執行；後台按伺服器台灣日期計算獎勵，忽略前端宣告的 XP。離線補傳在實際上傳日計入每日上限。

同一事件 ID 重試不重複加分；若事件 ID 帶了不同內容則拒絕。先提交含事件收據與絕對積分的學習檔案，再更新 Students；中斷後重試會修復原寫入而不再次加分。24 個分段欄位總上限約 96 萬字元，達上限會保留本機待傳事件並回報錯誤。

`LearningSchema.gs` 由 `scripts/build-learning-schema.cjs` 產生；詞庫或獎勵規則變更後必須重新產生並更新後台。完整 `gas/Code.gs` 是專案中的參考版本；未核對正式後台差異前，請使用上述小幅路由更新，不直接覆蓋整個正式程式。

## 驗證

涵蓋原關卡、雲端冒險存檔、場景、音樂與新大廳的測試。新測試包含每日上限、舊字去重、句型內容、單字與句型分開、保存失敗、晚到語音與雲端回應、身份隔離、訪客移轉、補傳期間新增事件、後台重試與寫入中斷。

真實裝置的麥克風辨識結果與正式大廳雲端同步，仍需在後台更新後由使用者實測。
